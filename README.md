## ABOUT
- Developed by Hanwon Jang
- 개발 기간: 2026.09

<br>
  
- 데스크톱 2열, 태블릿 유동형, 모바일 1열 레이아웃을 적용했습니다.
- 스크롤에 따라 프로필 사진과 그래픽이 조금 움직이고 상단에 읽기 진행률이 표시됩니다.
- 프로젝트 이미지 갤러리는 방향키로 이동하고 Escape 키로 닫습니다.
- 모션 최소화 설정과 키보드 포커스를 지원합니다.
- 운영체제의 모션 줄이기 설정을 켜면 등장·패럴랙스·hover 이동이 비활성화됩니다.
- 스크롤 위치와 브라우저의 기본 스크롤 동작은 그대로 유지합니다.
