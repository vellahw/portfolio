# 장한원 프론트엔드 포트폴리오

레트로 종이 콜라주, 블루·그린 포인트, 세리프 타이포그래피를 적용한 반응형 정적 웹 프로젝트입니다. 기존 포트폴리오의 소개·경력·교육·자격증, 업무경험 9개, 프로젝트 3개, 프로젝트 상세 이미지 21장, 연락처와 외부 링크를 보존했습니다. 마지막 첨부 사진을 프로필 이미지로 사용합니다.

## 실행

Node.js 18 이상에서 이 폴더를 열고 실행합니다. 패키지 설치는 필요 없습니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:5187 을 엽니다. `npm test`로 콘텐츠와 로컬 이미지·영상 존재를 검증합니다. `dist` 폴더를 정적 호스팅에 그대로 배포할 수 있습니다. 빌드가 필요하지 않습니다.

## 수정

- `dist/index.html`: 소개, 경력, 교육, 연락처
- `dist/data.js`: 업무경험과 프로젝트 내용
- `dist/style.css`: 색상, 타이포그래피, 반응형 레이아웃
- `dist/app.js`: 콘텐츠 표시와 키보드를 지원하는 프로젝트 이미지 갤러리
- `dist/motion.js`: 스크롤 등장 효과, 프로필 패럴랙스와 스크롤 진행 표시
- `dist/assets`: 프로필 사진과 기존 사이트에서 가져온 이미지·영상

데스크톱 2열, 태블릿 유동형, 모바일 1열 레이아웃을 적용했습니다. 영상은 사용자가 재생하며 자동 재생하지 않습니다. 프로젝트 이미지 갤러리는 방향키로 이동하고 Escape 키로 닫습니다. 모션 최소화 설정과 키보드 포커스를 지원합니다.

Pretendard CDN 웹폰트는 인터넷 연결 시 적용되며 오프라인에서는 시스템 글꼴로 표시됩니다. 사이트 내용과 프로젝트 이미지·영상 출처: https://iamhanwon.netlify.app/ (2026-09-13 확인). 레퍼런스 이미지는 디자인 방향에만 활용하고 결과물에 재배포하지 않았습니다. 외부 링크의 운영 상태는 각 사이트에 따라 달라질 수 있습니다.

링크의 밑줄·화살표, 카드의 들림·회전과 이미지 확대 hover 효과를 추가했습니다. 첫 화면은 순차적으로 등장하고, 섹션과 작업 카드는 화면에 들어올 때 한 번 부드럽게 나타납니다. 스크롤에 따라 프로필 사진과 그래픽이 조금 움직이고 상단에 읽기 진행률이 표시됩니다. 모바일에서는 프로필 패럴랙스를 생략합니다. 운영체제의 모션 줄이기 설정을 켜면 등장·패럴랙스·hover 이동이 비활성화됩니다. 스크롤 위치와 브라우저의 기본 스크롤 동작은 그대로 유지합니다.

Ticker와 업무경험 배경은 화면 전체 폭을 사용합니다. Hero, Profile, Experience, Projects 제목은 화면에 진입할 때 타이핑 효과로 표시됩니다. 링크 hover 밑줄은 제거했으며 첫 업무경험을 제외한 상세 업무와 프로젝트 역할은 항상 표시됩니다.

헤더는 최대 1600px이며 이메일을 표시합니다. Hero eyebrow와 제목의 타이핑 이후 나머지 요소가 등장합니다. 프로필은 hanwon.png 전체 구도를 사용하고 Hero 프로젝트 링크를 제거했습니다. 모바일 Ticker는 일시정지 가능한 무한 롤링입니다. Contact 배경도 전체 폭이며 컬러는 버건디(#873e47), 딥 네이비(#263747), 크림 골드(#f2d7a7)를 사용합니다.

헤더 배경은 전체 폭, 내부 .header-inner는 최대 1600px입니다. 포인트는 #36bfac, 업무경험 배경은 #974088입니다. 태그는 테두리·hover 효과 없이 포인트색 배경을 사용합니다. 업무경험과 프로젝트의 text-link, 연락처 링크는 화살표만 움직입니다. 기본 산세리프 글꼴은 Pretendard로 변경했습니다. 웹폰트 설정 출처: https://github.com/orioncactus/pretendard
